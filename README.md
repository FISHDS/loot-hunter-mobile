# 獵寶者 LOOT HUNTERS — 手機版
建立日期：2026-10-14

電腦版（D:\LOOT HUNTER CC）的手機版本：直向、單手操作、以掛機為主。
戰鬥、裝備、掉寶、存檔規則與電腦版完全相同，只換了一套適合手機的畫面。

## 怎麼在手機上玩

1. 用手機瀏覽器打開網址：https://fishds.github.io/loot-hunter-mobile/
2. 加到主畫面（之後就像 App，全螢幕、沒網路也能玩）：
   - iPhone（Safari）：按下方「分享」→「加入主畫面」
   - Android（Chrome）：按右上角「⋮」→「加到主畫面」或「安裝應用程式」
3. 存檔存在這支手機的瀏覽器裡。換手機前，到「更多 → 存檔與選單 → 匯出存檔」把文字存起來。

## 手機版和電腦版不一樣的地方

- 營地改成底部 5 個分頁：出征、裝備、星盤、工坊、更多（圖鑑、掛機設定、紀錄、音樂音效、畫質）。
- 點裝備會從下方滑出說明卡，卡上直接有「穿上／收藏／賣掉」。
- 每層整理背包：點裝備 → 點格子放下；可以旋轉，也可以直接賣掉。
- 星盤與地城畫面都可以兩指縮放；星盤可以單指拖曳。
- 新遊戲預設掛機模式。
- 切到別的 App 時戰鬥會暫停；離開超過 30 秒，回來時用離線收益結算，不會一口氣補算整段戰鬥。
- 「更多 → 畫質：省電」會減少光影與粒子特效，舊手機比較不卡、也比較省電。
- 主角是Q版大頭小男孩（像素手繪，不含任何照片），在地城裡畫得比電腦版大 1.3 倍。
- 「更多 → 傷害數字」可以選全部／只看技能／關閉。

## 給開發者

| 檔案 | 內容 |
|---|---|
| `index.html`、`m.css` | 手機版版面（m.css 疊在 style.css 上） |
| `js/ui.js`、`js/main.js` | 手機版畫面操作與主迴圈（由電腦版改寫，同步時不會被蓋掉） |
| `js/kid.js` | 手機版專用的主角大頭造型（同步時不會被蓋掉） |
| 其他 `js/*.js` | 與電腦版共用的核心規則與畫面 |
| `manifest.webmanifest`、`sw.js`、`icons/` | 加到主畫面與離線快取 |
| `同步核心.bat` | 把電腦版的核心規則複製過來 |
| `檢查同步.bat`（`tools/check_sync.ps1`） | 只檢查不修改：兩邊核心規則是否一致 |

**規矩：** 共用的核心檔案（上表「其他 `js/*.js`」）只在電腦版改，再同步過來；
手機版自己的東西只放在手機版專用的檔案裡。直接改手機版的共用檔案，下次同步就會被蓋掉。

更新流程：
1. 電腦版改好後，點兩下「同步核心.bat」。
2. 把 `sw.js` 的 `VERSION` 和 `index.html`、`sw.js` 裡的 `?v=` 版本號都加一（手機才會換成新版）。
3. 執行測試：`node --test tests/rules.test.js`
4. 點兩下「檢查同步.bat」，顯示「全部一致」才上傳。
5. 上傳到 GitHub（`git add -A`、`git commit`、`git push`），幾分鐘後網址就會更新。
